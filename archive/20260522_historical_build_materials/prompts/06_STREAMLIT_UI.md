# 06_STREAMLIT_UI.md

请开始第六阶段开发：Streamlit 初步交互界面。

请按照 UI_SPEC.md 实现。

要求：

1. 页面标题：绿电直连风光储多方案批量测算工具 V0.1；
2. 支持上传负荷 CSV、光伏 CSV、风电 CSV；
3. 支持用户选择时间列和数值列；
4. 支持设置容量搜索范围；
5. 支持设置储能参数；
6. 支持设置政策约束；
7. 显示方案数量预估；
8. 点击按钮后运行批量测算；
9. 显示方案汇总表；
10. 支持只看达标方案；
11. 支持下载方案汇总 Excel；
12. 支持下载逐小时明细；
13. 错误提示必须对普通用户友好；
14. 不要实现复杂美化；
15. 不要实现经济性评价。

建议文件：

- src/green_direct/ui/app.py

完成后：

1. 确认 `streamlit run src/green_direct/ui/app.py` 可以启动；
2. 如果无法自动运行，请说明手动运行方法；
3. 运行 pytest；
4. 不要进入 EXE 打包。
