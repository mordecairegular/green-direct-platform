# 01_CREATE_PROJECT_STRUCTURE.md

请开始第一阶段开发：创建项目结构。

要求：

1. 按 PROJECT_STRUCTURE.md 创建目录和空文件；
2. 创建 requirements.txt；
3. 创建 pyproject.toml；
4. 创建基本包结构；
5. 创建最小 README 运行说明；
6. 创建 tests/ 目录；
7. 不要实现核心算法；
8. 不要实现界面；
9. 不要实现经济性模块，只创建 economy/ 空接口目录。

完成后：

1. 展示创建了哪些文件；
2. 运行 `pytest`；
3. 如果没有测试，也要说明 pytest 是否能正常启动；
4. 不要进入下一阶段。
