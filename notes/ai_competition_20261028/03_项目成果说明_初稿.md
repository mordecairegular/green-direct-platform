# 绿电直连方案策划软件项目成果说明

## 一、项目概况

### （一）项目背景

2025 年 5 月，国家发展改革委、国家能源局印发《关于有序推动绿电直连发展有关事项的通知》（发改能源〔2025〕650 号）；2026 年 5 月，两部门印发《关于有序推动多用户绿电直连发展有关事项的通知》（发改能源〔2026〕688 号），将绿电直连由单一用户扩展至多个法人用户。688 号文对项目规划提出了明确的量化要求：

1. 按照以荷定源原则合理规划新能源装机规模；
2. 年自发自用电量占总可用发电量的比例不低于 60%，占总用电量的比例不低于 30%，2030 年前不低于 35%；
3. 并网型项目投产运行后，年上网电量原则上不超过总可用发电量的 20%；
4. 项目主责单位原则上由电源方与负荷方合资组建，也可由一方单独投资组建。

上述要求使绿电直连项目前期策划成为一个多约束问题，需要在全年逐小时尺度上同时回答三个问题：风电、光伏、储能如何配置；配置方案能否满足政策指标；在不同投资主体结构下，各方经济性是否可以接受。

传统工作方式以表格工具人工测算为主，存在以下不足：

1. 工作量大，单个项目从数据整理到形成方案比选结果不少于 5 个工作日；
2. 受人工工作量限制，可比选的容量组合数量有限；
3. 逐小时能量平衡、政策指标与经济性测算分处不同表格，口径不易统一，结果不易复核；
4. 难以同时反映电源方、负荷方和同一投资主体的不同收益口径。

### （二）项目目标

项目以绿电直连及源网荷储项目前期策划为应用场景，建设一套方案策划软件，实现以下目标：

1. 在全年 8760/8784 小时尺度上完成风光储容量方案的批量技术仿真；
2. 将政策指标内嵌于方案筛选过程，自动识别达标方案及不达标原因；
3. 在技术仿真结果基础上开展多视角经济性测算；
4. 从大量候选方案中推荐少数代表方案，并给出推荐依据；
5. 输出可逐小时、逐年复核的明细数据和报告材料，缩短前期策划周期。

### （三）主要成果

1. **软件系统**。形成包含项目启动、方案仿真、经济性测算、方案推荐、图表概览、成果导出六个功能模块的方案策划软件，【待补：AI 助手功能】。
2. **工程应用**。软件已在 50 余个绿电直连、源网荷储项目中投入试用，单个项目由数据处理到取得初步结果的时间由不少于 5 个工作日缩短至约 1 个工作日。
3. **技术文档**。形成计算口径说明、接口文档、测试用例、专家审查材料、部署与运维说明等配套文档。
4. 【待补：软件著作权登记、内部评审、获奖等其他成果】。

## 二、创新性

### （一）以代表方案推荐替代全量方案罗列

通用的风光储规划工具通常采用"逐时仿真加容量组合枚举"的方法，并以全部组合的结果表作为输出。本软件保留枚举作为内部搜索手段，但不以全量结果表作为主要输出，而是经政策筛选、经济性测算和多视角排序后，输出少数代表方案。每个代表方案均附有容量配置、关键技术指标、经济指标、推荐依据，并可追溯至全年逐小时明细和逐年现金流。用户由"阅读数百行结果表"转为"比较若干有依据的方案"。

### （二）将政策约束与多主体利益同时纳入方案评价

针对 688 号文允许电源方与负荷方合资或单方投资的规定，软件设置四个推荐席位，分别回应不同投资主体结构下的决策关注点：

| 推荐席位 | 适用情形 | 排序依据 |
|---|---|---|
| 同一主体 FIRR 最优 | 电源与负荷由同一主体投资 | 计入购电节费的税前财务内部收益率 |
| 电源侧 FIRR 最优 | 电源方独立投资 | 电源侧项目投资财务内部收益率 |
| 负荷侧可成交收益最优 | 电源方与负荷方分属不同主体 | 在电源侧 FIRR 不低于设定门槛的前提下，负荷侧收益最大 |
| 工程代表方案 | 技术比选与汇报 | 默认为政策达标方案中投资最小者，可切换为低弃电、高绿电占比、高自发自用 |

所有席位均在政策达标方案中排序。负荷侧席位设置电源侧最低可接受 FIRR 门槛，避免推荐对电源方不具备可行性的方案。同一方案命中多个席位时合并展示；席位条件不满足时显示待定状态及原因，不作静默省略。

### （三）建立可复核的计算结果链

软件规定技术仿真结果为唯一事实来源。政策评价、经济性测算、推荐排序、图表和报告均只读取技术仿真结果，不重新推导调度过程，各模块以方案编号关联。由此保证推荐结论、经济指标与逐小时能量流向一一对应，满足设计成果审查和专家复核的要求。

### （四）人工智能应用

1. **产品层面**：【待补：AI 助手的功能定位、所用模型、输入输出、使用场景】。按照项目既定架构约束，AI 生成的解读内容须读取技术仿真和经济性结果，不改变计算结果【待确认：与最新版实现一致】。
2. **研发层面**：软件由熟悉绿电直连业务的技术人员主导研发，借助 AI 编程智能体完成需求梳理、口径文档、架构设计、代码编写、测试编写、代码评审和部署脚本等工作【待确认：是否列明所用工具名称】。为控制 AI 生成代码的质量风险，项目建立了四项约束机制：
   - 以规则文件规定计算底线、架构方向和文档维护要求，约束 AI 的开发行为；
   - 以自动化测试固化核心计算口径，每次修改核心算法后执行全量测试；
   - 以产品打磨记录逐条留存需求变更与口径决策，保证研发过程可追溯、可接续；
   - 以专家审查材料和多个 AI 工具交叉评审，对计算口径、代码质量和界面设计进行校核。

### （五）与行业需求的契合

1. 政策指标（自发自用率、绿电占比、上网比例）直接参与方案筛选，门槛值可按政策和省级细则调整；
2. 风光出力标幺曲线中的负值按电源站用电处理，不作截断，符合工程实际；
3. 经济性输入按电费单科目组织，默认值按湖南 110kV 工商业两部制用户电费构成预置，并支持上传 8760 小时下网电价曲线；
4. 输出内容对应设计院前期咨询、可研编制和方案汇报的成果需要。

## 三、技术实现与解决方案

### （一）总体架构

软件采用 Python 开发，界面基于 Streamlit，数据处理采用 pandas、NumPy，图表采用 Plotly，表格导出采用 openpyxl、XlsxWriter。系统按职责分层如下：

| 层次 | 模块 | 主要职责 |
|---|---|---|
| 数据层 | 数据读取与校验 | 曲线文件读取、编码与时间列识别、曲线类型识别、数据质量诊断 |
| 计算层 | 核心仿真、批量运行 | 单方案逐小时仿真、储能调度、指标汇总、候选方案生成与批量计算 |
| 评价层 | 经济性测算、推荐引擎 | 多视角年度现金流与财务指标、推荐席位排序 |
| 服务层 | 服务编排、结果存储 | 技术、经济、推荐流程编排，项目结果保存与恢复，后台任务管理 |
| 展示层 | 可视化、导出、界面 | 图表、Excel/CSV/ZIP、Word 报告、六页工作流界面 |
| 智能层 | AI 助手 | 【待补】 |

### （二）业务流程

软件按项目前期策划流程组织为六个页面：

1. **项目启动台**：创建或选择项目，展示项目准备度、下一步建议和交付状态；
2. **方案仿真**：上传负荷、光伏、风电曲线，设置候选方案范围、储能参数和政策约束，执行批量技术仿真；
3. **经济性测算**：录入建设投资、运维成本、收入税金和电费单参数，一次完成全部经济性视角测算；
4. **方案推荐**：展示推荐席位、容量配置、关键指标和推荐依据，通过三维经济性对比图定位方案；
5. **图表概览**：围绕推荐方案展示关键图表、典型日和逐小时曲线；
6. **成果导出**：导出方案汇总、逐小时明细、年度现金流、图表包和 Word 报告。

### （三）关键技术

#### 1. 数据接入与诊断

支持批量上传曲线文件，按文件名自动识别曲线类型，自动识别文件编码、时间列和数值列；支持 8760 小时平年和 8784 小时闰年数据；对空值、负值、标幺值大于 1、时间戳不一致等问题给出分级提示。

#### 2. 逐小时能量平衡与储能调度

对每个候选方案逐小时计算风光出力、站用电、负荷、储能充放电、上网、弃电和下网电量。调度顺序为：新能源优先供应负荷，富余电量优先为储能充电，其余按上网规则上网或弃电；新能源不足时储能放电，仍不足部分由电网供应。储能运行遵循以下约束：

1. 仅由富余新能源充电，不从电网充电；
2. 同一小时内不同时充电和放电；
3. 不放电上网；
4. 荷电状态逐小时滚动，且不超出上下限；
5. 充放电受功率、容量和充放电效率约束。

年度上网比例按运行中累计额度实施硬约束，额度用尽后富余电量转为弃电；可选设置与电网交换功率限制，同时约束上网和下网功率。

#### 3. 政策指标计算与达标判断

软件计算自发自用率（自发自用电量与新能源总可用发电量之比）、绿电占比（自发自用电量与用户总用电量之比）、上网比例、弃电率、下网电量比例、储能年等效循环次数等指标，按设定门槛判断方案是否达标，并逐项列出不达标原因。

#### 4. 多视角经济性测算

经济性测算读取技术仿真结果，不改变调度结果，包括三个视角：

1. **电源侧**：按项目投资现金流口径，计算建设期投资、运营期收入、成本、税费和储能更换，输出年度现金流、财务净现值、财务内部收益率、静态和动态投资回收期；
2. **同一主体**：将自发自用电量形成的购电节费计入收益，计算税前现金流和财务内部收益率；
3. **负荷侧**：以自发自用电量乘以可减少的购网费用单价与绿电结算价之差，计算负荷侧年度收益，可选计入环境价值。

计算口径的主要处理包括：储能更换年份取循环寿命与日历寿命先到者；电费按到户综合电价、线损、系统运行费、输配电价、政府基金及附加等科目推导，自发自用绿电默认仍缴纳输配电价和政府基金及附加；支持 8760 小时下网电价曲线；财务内部收益率求解先扫描净现值曲线，仅在存在唯一稳定解时输出，以正确处理储能更换引起的现金流多次变号。

#### 5. 代表方案推荐

推荐引擎先筛选政策达标方案，再按各席位指标排序，生成推荐组合。经济性测算未完成时，工程代表方案仍可先行给出，其余席位显示待定状态。

#### 6. 大批量计算与结果管理

1. 采用"汇总优先、明细按需"策略：批量计算阶段只保留方案汇总，推荐方案或用户选定方案需要图表、报告或复核时再生成逐小时明细，控制内存和存储占用；
2. 支持多进程并行计算，计算前按方案数、小时数和并行进程数预估耗时，超过阈值时提示确认；
3. 提供本地项目库，保存输入曲线、配置、技术汇总、经济性汇总、推荐组合和交付产物，支持跨会话恢复；
4. 提供可选的多人试用支撑功能，包括账号登录、项目成员管理、导出权限控制、审计日志和后台任务处理。

#### 7. 成果输出

输出方案汇总 Excel、逐小时明细 CSV/ZIP、年度现金流明细、HTML 交互图表包、适用于 Word 排版的 PNG 图表包，以及 Markdown 和 DOCX 格式的方案说明报告。

### （四）质量保障

1. **测试**：建立 455 个自动化测试用例，覆盖储能调度约束、指标计算、经济性测算、推荐排序、电价曲线、结果持久化、权限控制等；【待确认：以开发机全量测试结果为准】；
2. **口径管理**：核心计算口径以规格文档固定，口径调整须同步修改测试和文档；
3. **发布检查**：配置持续集成质量检查和部署前自检脚本，覆盖测试、运行环境、依赖一致性和数据存储状态。

### （五）适用范围与边界

1. 当前版本适用于并网型绿电直连和源网荷储项目的前期方案策划；
2. 柴油发电机组及离网、并网加备用等运行模式已完成调度逻辑设计，尚未纳入软件；
3. 储能调度采用规则化策略，不包含电价套利和数学规划优化；
4. 经济性测算用于方案筛选和排序，不考虑融资，不替代正式财务评价。
