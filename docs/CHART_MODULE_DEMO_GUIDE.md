# 图表模块 Demo 使用与验收说明

## 1. 分支

当前图表模块 Demo 开发分支：

```bash
feature/chart-module-demo
```

## 2. 规划核对结论

图表模块规划文档的方向满足下一步开发要求，尤其是以下边界是正确的：

- 图表模块只读取已有 `summary` 和 `hourly_detail`；
- 不重写逐小时能量平衡、储能 SOC、上网、弃电等核心计算；
- 字段不一致时通过适配层处理；
- 每个图表函数返回统一的 `ChartResult`；
- 缺字段时返回友好提示，不让页面崩溃；
- 第一阶段不做经济性评价。

结合当前项目结构做了两点调整：

1. 未覆盖项目根目录已有 `AGENTS.md`，避免把讨论稿直接替换正式约束。
2. 图表模块未放在讨论稿建议的 `modules/visualization/`，而是放在当前包结构更一致的 `src/green_direct/visualization/`。

## 3. 启动方式

```bash
streamlit run src/green_direct/ui/app.py
```

或访问当前本地服务：

```text
http://localhost:8501
```

## 4. 快速体验

页面打开后，可以直接点击主页面中的：

```text
一键生成 Demo 结果
```

该按钮会使用 `samples/` 目录下的负荷、光伏、风电示例曲线，并自动生成 20 个小规模风光储方案。生成后页面下方会出现：

```text
图表分析
```

## 6. 导出能力

每张图表在“图表数据与导出”折叠区提供：

- HTML；
- Excel 数据；
- 口径说明 Markdown；
- PNG。

PNG 导出依赖当前环境的 Plotly/Kaleido 支持。如果环境不可用，页面会给出提示，不影响 HTML 和 Excel 导出。
