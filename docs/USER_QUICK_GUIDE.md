# 绿电直连测算工具本地试用说明

## 1. 启动

1. 解压试用包到本地目录。
2. 双击根目录下的 `START_GREEN_DIRECT_LOCAL_TRIAL.bat`。
3. 首次运行会自动创建 `.venv` 并安装运行依赖，可能需要几分钟。
4. 浏览器会自动打开本地页面，通常是 `http://localhost:8503`。

使用期间不要关闭黑色启动窗口。关闭后，网页后台服务也会停止。

如果浏览器没有自动打开，可以在启动窗口里找到实际地址；程序会在 `8503` 到 `8515` 之间自动选择可用端口。

## 2. 电脑要求

- Windows 电脑；
- 已安装 Python 3.10 或更新版本；
- 首次运行时需要能访问 Python 包下载源。

如果电脑没有 Python，或公司网络无法安装依赖，请反馈给项目维护人，需要另做离线包或免安装 EXE。

## 3. 试用方式

只想快速体验时，可以先使用页面里的 Demo 数据。

正式测算时，按网页里的 01-06 页面顺序操作：

1. 准备项目和输入数据；
2. 上传负荷、光伏、风电曲线；
3. 设置容量搜索范围、储能参数和政策约束；
4. 运行技术仿真；
5. 运行经济性测算和方案推荐；
6. 查看图表，并按页面已有入口下载当前可用结果。

## 4. 本地试用版保留内容

- 保留当前 Streamlit 网页界面和六步工作流；
- 保留 Demo、曲线上传、技术仿真、经济性测算、推荐、图表和已有下载入口；
- 保留本地浏览器访问方式，操作逻辑与当前网页版本一致。

## 5. 本地试用版边界

- 本地试用包不是公网多人网站；
- 本次不把正式报告导出作为验收项；
- 经济性测算仍是轻量试算，不用于最终投资决策；
- 大方案池可能需要较长时间，建议先用较小容量范围体验流程。

## 6. 常见问题

### 网页打不开

重新双击 `START_GREEN_DIRECT_LOCAL_TRIAL.bat`，等待窗口显示本地访问地址后再打开浏览器。

### 黑色窗口能不能关

不能。它是本地后台服务窗口，关闭后网页会断开。

### 首次启动很慢

首次启动要创建 `.venv` 并安装依赖。后续再次启动会快很多。

### CSV 上传后列名乱码

软件会自动尝试多种中文编码。只要列名和数据能被正确识别，一般不影响试用。
