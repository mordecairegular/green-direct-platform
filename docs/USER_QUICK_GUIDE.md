# 绿电直连风光储测算工具使用说明

## 1. 启动软件

1. 解压软件包。
2. 双击：

```text
启动绿电直连测算工具.bat
```

3. 等待浏览器自动打开。
4. 如果浏览器没有自动打开，可以手动访问：

```text
http://localhost:8501
```

使用软件期间，请不要关闭弹出的黑色启动窗口。关闭该窗口后，网页会失去后台服务。

## 2. 快速体验 Demo

如果只是想先看软件效果：

1. 打开软件页面。
2. 点击：

```text
一键生成 Demo 结果
```

3. 等待测算完成。
4. 在页面下方查看：

```text
图表分析：方案图谱
```

## 3. 正式测算流程

### 第一步：上传数据

在左侧“数据上传”区域上传 3 个 CSV 文件：

- 负荷 CSV；
- 光伏 CSV；
- 风电 CSV。

软件会自动识别常见列名。如果识别不准确，可以手动选择时间列和数值列。

### 第二步：设置容量范围

在“容量搜索范围”中设置：

- 光伏容量起始、结束、步长；
- 风电容量起始、结束、步长；
- 储能功率起始、结束、步长；
- 储能时长选项。

软件会显示“方案数量预估”。如果方案数太大，建议增大步长或缩小范围。

### 第三步：设置储能和政策参数

通常可以先使用默认值。

需要时可以展开：

- 储能参数；
- 上网与政策约束；
- 高级参数。

### 第四步：开始测算

点击：

```text
开始测算
```

测算完成后，页面会显示：

- 总方案数；
- 达标方案数；
- 高级结果表与下载入口；
- 经济性评价 V1；
- 图表分析：方案图谱。

## 4. 查看图表

测算完成后，在页面下方进入“图表分析：方案图谱”。

常用页面：

- 方案总览：查看系统代表方案、用户加入方案和当前方案核心指标；
- 能量流向：查看年度新能源构成和能源流向；
- 运行时序：查看四季典型日和折叠的 8760h 曲线；
- 经济性分析：在已计算经济性 V1 后查看 FNPV、FIRR、回收期和多方案对比。

## 5. 导出结果

页面提供以下导出：

- 方案汇总 Excel；
- 全部逐小时明细 ZIP；
- 当前方案逐小时 CSV；
- 经济性结果 Excel。

大表和下载入口默认收起在“高级：结果表、筛选与下载”中。

## 6. 常见问题

### 网页打不开

原因通常是后台服务没有启动。

解决方法：

1. 关闭原来的浏览器页面。
2. 重新双击 `启动绿电直连测算工具.bat`。
3. 等待浏览器自动打开。

### 黑色窗口能不能关

不能。黑色窗口是软件后台服务。关掉它，网页就不能继续使用。

### 页面显示端口被占用

说明已有一个软件服务正在运行。可以直接访问：

```text
http://localhost:8501
```

如果仍打不开，重启电脑后再双击启动文件。

### CSV 上传后列名乱码

软件会自动尝试多种中文编码。只要能正确识别列名和数据，一般不影响使用。

## 7. 当前版本边界

当前版本用于技术测算、经济性 V1 试算和少数方案图表复核。

当前经济性 V1 暂不考虑：

- 贷款和还本付息；
- 流动资金；
- 期末残值回收；
- 留抵退税；
- 复杂融资模型。
