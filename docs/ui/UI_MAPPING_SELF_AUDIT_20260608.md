# UI Mapping Self Audit - 2026-06-08

本文件记录本次围绕“原型 UI 与底层功能映射”的自查结果。边界：只审计和调整 UI 展示层、状态映射、图表呈现和文档，不修改技术仿真、经济性计算、推荐排序或图表数据口径。

## 1. 下网电价曲线导入链路

### 发现

- 既定口径是：下网电价曲线作为项目级输入，在“方案仿真”页上传；进入“经济性测算”后自动使用，不在经济性页二次上传。
- 原 UI 中“批量上传曲线 CSV”只识别负荷、光伏、风电三条技术曲线。
- 如果用户把下网电价曲线和三条技术曲线一起放入批量上传，文件会被提示“未能识别”，虽然下方另有高级电价曲线入口。
- 这会让用户误以为“批量导入不支持电价曲线”或“经济性参数忘了接电价曲线”。

### 已改

- 批量上传入口改为“批量上传项目曲线文件”。
- 技术曲线仍只支持 CSV，继续分配到负荷、光伏、风电。
- 下网电价曲线可在同一个批量上传入口中识别 CSV / XLSX / XLSM。
- 识别到的下网电价曲线保存到 `project_price_curve_data` / `project_price_curve_meta`。
- 经济性页继续不提供二次上传入口，只展示当前使用的项目级曲线。
- 经济性结果保存 `price_curve_diagnostics`，页面展示价格曲线对齐告警。

### 保持不变

- `read_price_curve()`、`apply_price_curve_to_summary()`、`run_economic_study()` 均未修改。
- 下网电价曲线只影响经济性测算和推荐排序，不改变技术调度。
- 绿电结算价、上网电价、环境价值和税率仍由网页端固定参数输入。

## 3. 图表概览设计调整

### 发现

- 原“多方案关键指标对比”是普通柱状图，只显示指标值，不能直接表达“距离政策底线还有多少余量或缺口”。
- 原“容量配置横向对比”把光伏容量、风电容量、储能功率、储能容量混在同一柱状图轴上，单位和解释都不够清晰。
- “典型日、能量流向与完整图表复核”被放在高级折叠区，但这些是复核核心，不应默认隐藏。
- 嵌入的完整图表复核仍有“方案总览”页签，和图表概览页顶部主图重复。

### 已改

- 政策指标主图改为“政策底线余量矩阵”：显示绿电占比、自发自用率、上网比例与当前阈值的差距。
- 容量配置主图改为“容量配置指纹矩阵”：用颜色深浅表达相对规模，格内保留真实容量值。
- 详细图表复核不再放入高级折叠区。
- 详细图表复核使用图表概览页统一选择的方案组合，并通过“详细图表方案”选择能量流向、运行时序和经济性分析的对象。
- 嵌入详细图表时不重复展示“方案总览”页签。

### 2026-06-08 追加修正

- 政策底线矩阵补入 `curtail_rate` 弃电率列。当前 02 页没有弃电率政策阈值输入，因此该列按“低优运行指标”展示，不伪造政策红线。
- “容量配置指纹矩阵”改名为“容量配置结构矩阵”，避免术语过于抽象。
- 容量配置矩阵色带降低饱和度，最高值不再使用过深蓝色。
- 图表概览页新增“详细图表方案（全部已计算方案）”下拉框。默认仍取推荐组合方案，但允许直接切换到任一已计算方案。
- 方案组合选择和详细方案选择下方均展示方案编号和光伏/风电/储能规模，避免只看 `scenario_id` 无法判断配置。
- 嵌入图表复核时隐藏旧的“图表分析：方案图谱”标题，当前方案条改为“当前复核方案”。

## 4. 下一步建议

1. 把价格曲线来源、识别字段、对齐模式写入简版报告和图表包 meta。
2. 在经济性页增加“价格来源分解”卡片，减少用户误以为固定价仍参与曲线模式的困惑。
3. 将 `chart_ui.py` 内部方案选择继续收敛为可复用组件，长期只保留一个图表方案选择状态。
4. 再做一次浏览器验收：批量上传三条技术曲线 + 一条下网电价曲线，确认经济性页显示曲线模式并禁用冲突控件。
## 5. 2026-06-08 追加：指定单方案与图表按钮

- 02 方案仿真新增 `容量范围遍历 / 指定单方案` 两种候选方案池输入方式。指定单方案只把用户输入的光伏、风电、储能功率、储能容量转换为单一 `scenario_grid`，仍走原 `run_technical_study()` 链路，不新增旁路计算器。
- 指定单方案校验只发生在 UI 编排层：纯储能/无绿电来源不进入候选池；储能功率和储能容量必须同时为 0 或同时大于 0；储能时长由 `储能容量 / 储能功率` 推导。
- 02 三栏宽度改为导入曲线更紧凑、候选方案池更宽，避免指定容量输入过挤。
- 05 详细图表复核中的推荐方案块改为原生按钮，点击按钮会切换下方详细图表；下拉框继续保留“全部已计算方案”入口。
- Streamlit 限制：按钮点击不能在 selectbox 实例化后直接改同一个 session key，因此按钮写入 `_chart_overview_pending_detail_scenario`，下一次渲染前再同步到 `chart_overview_active_detail_scenario`。
- 绿电前后综合到户价暂不实现，原因是固定价模式和曲线模式的展示口径需要用户确认，不能把节费单价误当成完整到户电价。
