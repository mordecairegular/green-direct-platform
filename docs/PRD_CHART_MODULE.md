# 绿电直连风光储配置方案典型图表制作模块 PRD

> **状态：讨论稿**
>
> 本文档为“绿电直连风光储多方案批量测算软件”图表模块的产品需求讨论稿，供后续使用 Codex / Claude / 人工开发时参考。  
> 后续进入正式开发前，应结合现有项目代码结构、字段名称、输出文件格式和 Streamlit 页面实际情况进一步校核。

---

## 1. 模块定位

本模块是“绿电直连风光储多方案批量测算软件”的图表分析与人工复核模块。

本模块不负责经济性评价，不重新计算能量平衡，不替代现有方案计算模块。

本模块的核心目标是：

1. 将现有方案计算结果图形化；
2. 帮助用户理解方案为什么达标或不达标；
3. 帮助用户发现风、光、储容量配置是否偏大、偏小或利用不足；
4. 帮助用户复核上网比例、弃电、下网、站用电、电网交换功率限制等关键约束；
5. 为后续可研报告、汇报材料和经济性排序模块预留图表与数据接口。

---

## 2. 模块入口

### 2.1 入口一：从方案计算结果页进入

用户完成批量测算后，在方案汇总表中勾选方案，然后点击：

- 查看图表；
- 加入对比；
- 导出图表包。

不要求用户手动输入 `scenario_id`。

### 2.2 入口二：独立图表分析入口

用户从主菜单进入“图表分析”页面，可以选择已有项目、已有测算结果或直接输入少量临时方案进行快速制图。

### 2.3 入口三：未来经济性评价模块进入

后续经济性排序完成后，可选择经济性排序前 N 个方案进入图表模块进行技术复核。

---

## 3. 用户角色

| 用户角色 | 主要需求 |
|---|---|
| 咨询工程师 | 检查方案是否符合绿电直连技术逻辑 |
| 项目业主 | 看懂风、光、储配置为什么这样选 |
| 技术复核人员 | 追溯逐小时能量平衡和异常时段 |
| 报告编制人员 | 导出可放入报告的图表和数据 |
| 后续经济性模块用户 | 对候选方案做技术解释和筛选 |

## 4. 设计原则

### 4.1 共用基础参数

图表模块必须读取现有项目参数和方案参数，不得要求用户重复输入已有参数。

应共用的参数包括但不限于：

- 负荷曲线；
- 光伏标幺曲线；
- 风电标幺曲线；
- 光伏容量；
- 风电容量；
- 储能功率；
- 储能容量或储能时长；
- SOC 参数；
- 储能效率；
- 上网比例限制；
- 电网交换功率限制；
- 是否启用相关约束。

### 4.2 自动识别时间信息

可以由输入文件自动识别的内容，不得让用户重复指定。

应自动识别：

- 时间步长；
- 8760 小时普通年或 8784 小时闰年；
- 起止时间；
- 是否有缺失时刻；
- 是否有重复时刻；
- 是否存在光伏、风电负标幺值。

### 4.3 图表模块保持独立

图表模块应作为独立子模块存在，尽量不影响现有方案计算模块。

推荐目录结构：

```text
modules/
  visualization/
    __init__.py
    chart_contracts.py
    chart_data.py
    single_scenario_charts.py
    multi_scenario_charts.py
    heatmap_charts.py
    export_charts.py
    chart_ui.py
```

### 4.4 不重写计算逻辑

图表模块不得重新实现以下核心逻辑：

- 新能源优先供负荷；
- 富余新能源充储能；
- 储能 SOC 滚动；
- 储能充放电限制；
- 上网比例限制；
- 弃电判断；
- 下网缺口判断；
- 站用电抵扣逻辑；
- 电网交换功率约束。

图表模块可以基于已有字段做展示性聚合，例如日度、月度、年度、热力图透视，但不得重新定义计算口径。

---

## 5. 图表选择机制

图表模块不得默认一次性生成所有图表。

应提供：

1. 默认核心图表包；
2. 储能诊断图表包；
3. 电网交换图表包；
4. 政策指标图表包；
5. 多方案对比图表包；
6. 全部勾选；
7. 自定义选择。

## 7. 典型日、极端日、异常日

图表模块应支持四类日期选择。

### 7.1 用户自选日

用户手动选择某一天查看 24 小时运行图。

### 7.2 典型日

系统自动推荐：

- 春季典型日；
- 夏季典型日；
- 秋季典型日；
- 冬季典型日；
- 光伏典型高发日；
- 风电典型高发日；
- 源荷匹配较好日。

### 7.3 极端日

系统自动推荐：

- 最大负荷日；
- 最小负荷日；
- 光伏最低发电日；
- 风电最低发电日；
- 风光合计最低日；
- 风光合计最高日；
- 最大弃电日；
- 最大下网日电量；
- 最大下网功率日；
- SOC 最低日；
- SOC 最高日。

### 7.4 异常日

系统根据计算结果自动识别：

- 下网缺口最大日；
- 弃电最大日；
- SOC 触底且下网明显的日；
- SOC 触顶且弃电明显的日；
- 电网交换功率限制触发日；
- 年度上网比例约束触发日。

## 8. 典型日源网荷储平衡图设计

典型日/极端日图是本模块第一核心图表。

不应直接展示全年 8760 个点。

应采用单日 24 小时展示，建议由三部分组成。

### 8.1 负荷供给来源图

横轴：0–23 小时  
纵轴：功率，万千瓦

堆叠项：

- 新能源直供负荷；
- 储能放电供负荷；
- 公共电网下网；
- 下网缺口。

叠加线：

- 负荷曲线。

### 8.2 新能源富余去向图

横轴：0–23 小时  
纵轴：功率，万千瓦

堆叠项：

- 储能充电；
- 上网；
- 弃电。

叠加线：

- 净新能源出力。

### 8.3 储能 SOC 图

单独展示 SOC，不与功率混用同一纵轴。

展示：

- SOC 曲线；
- SOC 上限；
- SOC 下限；
- 初始 SOC。

## 9. 热力图设计

年度热力图应采用 365×24 或 366×24 的结构。

横轴：日期或年内第几天  
纵轴：小时  
颜色：指标数值

可切换指标：

- 负荷；
- 新能源净出力；
- 下网功率；
- 上网功率；
- 弃电功率；
- SOC；
- 下网缺口；
- 交换功率限制触发状态。

---

## 10. 政策参数

默认政策阈值：

- 年上网电量占新能源总可用发电量比例：不高于 20%；
- 新能源自身消纳电量占新能源总可用发电量比例：不低于 60%；
- 新能源自身消纳电量占项目总用电量比例：不低于 30%；
- 2030 年前目标值可切换为不低于 35%。

用户应可自定义阈值。

如果用户自定义阈值，界面必须显示：

> 当前图表和达标判断基于自定义政策参数，仅用于本次复核展示。

---

## 11. 多方案选择规则

用户应通过方案汇总表勾选方案，不应手动输入 `scenario_id`。

推荐限制：

- 叠加折线图最多 5 个方案；
- 对比柱状图可支持 20 个方案；
- 散点图可支持更多方案；
- 单方案诊断图一次聚焦 1 个方案。

---

## 12. 输出形式

### 12.1 页面展示

- Streamlit 交互图；
- 指标卡片；
- 口径说明；
- 异常时段表；
- 图表数据预览；
- 图表选择组件。

### 12.2 文件导出

应支持导出：

- PNG 或 SVG 静态图；
- HTML 交互图；
- Excel 图表数据；
- Markdown 图表说明；
- ZIP 图表包。

第一阶段至少应实现：

- PNG 导出；
- HTML 导出；
- Excel 数据导出。

---

## 13. 验收标准

第一阶段 demo 应满足：

1. 可以从已有方案汇总表勾选方案；
2. 可以展示至少 8 张核心图表；
3. 可以生成典型日/极端日 24 小时源网荷储平衡图；
4. 可以生成年度 365×24 热力图；
5. 可以生成月度电量结构图；
6. 可以生成 SOC 图和储能充放电图；
7. 可以生成政策指标对比图；
8. 可以生成弃电率 vs 自发自用率散点图；
9. 每张图都能返回图对象、图表数据和口径元信息；
10. 图表模块不改变现有计算结果；
11. 可以导出图表和图表数据；
12. 原有方案计算模块仍能正常运行。
