## 3. 开发原则

### 3.1 必须遵守

- 不得重写现有能量平衡核心逻辑；
- 不得改变现有计算模块字段含义；
- 不得破坏现有批量测算功能；
- 图表模块只能读取已有 summary 和 hourly_detail；
- 可以基于已有字段做展示性聚合；
- 每张图必须返回图对象、图表数据和口径元信息；
- 每张图必须能在字段缺失时给出友好提示；
- 页面 UI 应尽量沿用现有 Streamlit 风格；
- 优先保证 demo 可运行，而不是一次性追求完美。

### 3.2 禁止事项

不得：

- 为了画图重新实现储能调度；
- 为了画图重新计算 SOC；
- 为了画图重新判断弃电；
- 为了画图重新判断上网；
- 为了画图重新处理站用电；
- 在图表模块中硬编码新的政策口径；
- 大范围重构现有项目；
- 删除现有功能；
- 修改无关文件。

## 7. Streamlit UI 要求

请在现有 Streamlit UI 中增加“图表分析”入口。

### 7.1 页面结构建议

```text
图表分析
  Tab 1：方案选择
  Tab 2：单方案诊断
  Tab 3：典型日 / 极端日分析
  Tab 4：储能分析
  Tab 5：电网交换分析
  Tab 6：多方案对比
  Tab 7：导出
```

### 7.2 方案选择

用户应通过表格勾选方案，不应手动输入 `scenario_id`。

如果现有 UI 尚不支持表格勾选，可先用 multiselect 实现：

```python
st.multiselect("选择方案", scenario_id_list)
```

但界面文案应面向普通用户，避免要求用户理解内部 ID。

### 7.3 图表选择

请提供图表选择组件：

- 默认核心图表；
- 储能诊断图表；
- 电网交换图表；
- 政策指标图表；
- 多方案对比图表；
- 全部勾选；
- 自定义选择。

### 7.4 日期选择

典型日/极端日图应支持：

- 用户自选日；
- 最大负荷日；
- 最大弃电日；
- 最大下网日；
- 光伏最低日；
- 风电最低日；
- 风光合计最低日；
- SOC 最低日；
- SOC 最高日。

如果某些日期无法识别，应显示提示而不是报错。
