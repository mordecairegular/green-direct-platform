# 独立方案遍历试用程序使用说明

状态：试用入口说明
最近更新：2026-05-27

## 1. 用途边界

`GreenDirectBatchTrial` 是一个低门槛 Windows 试用程序，只包装当前 V0.1 风光储技术遍历能力：

- 读取负荷、光伏、风电三条 CSV 曲线；
- 枚举风电、光伏、储能容量组合；
- 调用现有逐小时技术仿真；
- 导出方案概览 Excel；
- 导出全部成功方案的逐小时详表 ZIP；
- 保存本次测算配置、警告和错误记录。

它不包含完整 Streamlit 主界面、图表模块、经济性评价和推荐引擎。该入口用于内部试算和同事反馈，不代表长期主产品体验回到“全量枚举表优先”。

## 2. 启动方式

构建后双击：

```text
dist\GreenDirectBatchTrial\GreenDirectBatchTrial.exe
```

发给同事试用时，复制整个文件夹：

```text
dist\GreenDirectBatchTrial\
```

不要只复制单个 exe，否则示例文件、文档或依赖资源可能缺失。

## 3. 输入文件

需要准备三份 CSV：

| 文件 | 必要列 | 说明 |
|---|---|---|
| 负荷 CSV | 时间列、负荷列 | 负荷单位为万千瓦，不能为负 |
| 光伏 CSV | 时间列、光伏列 | 光伏标幺值，可为负；负值按站用电处理 |
| 风电 CSV | 时间列、风电列 | 风电标幺值，可为负；负值按站用电处理 |

三份文件必须行数一致、时间戳逐行一致。当前支持 8760 行和 8784 行。

如果文件只有两列，程序默认把第一列识别为时间列、第二列识别为数值列。

## 4. 参数填写

主要参数包括：

- 光伏容量起止和步长，单位为万千瓦；
- 风电容量起止和步长，单位为万千瓦；
- 储能功率起止和步长，单位为万千瓦；
- 储能时长选项，单位为小时，多个值用英文或中文逗号分隔；
- SOC 初始值、下限、上限；
- 储能充电效率、放电效率、循环寿命；
- 自发自用率、绿电占比、上网比例等政策约束；
- 电网交换功率限制，留空表示不限制；
- 方案数提醒阈值。

程序会跳过没有绿电来源的组合，即 `pv_capacity <= 0` 且 `wind_capacity <= 0` 的组合不会进入候选池。

## 5. 输出文件

每次运行会在输出目录下生成一个运行文件夹：

```text
batch_trial_YYYYMMDD_HHMMSS\
```

其中通常包含：

| 文件 | 说明 |
|---|---|
| `方案概览_*.xlsx` | 每个成功方案一行的年度技术指标和政策判断 |
| `方案详表_*.zip` | 每个成功方案一个逐小时 CSV |
| `本次测算配置_*.json` | 输入文件、容量范围、储能参数、政策参数和编码信息 |
| `结果说明.txt` | 本次运行的成功数、失败数、警告数和文件说明 |
| `方案计算错误_*.csv` | 仅在部分方案失败时生成 |
| `警告提示_*.txt` | 仅在存在输入或计算警告时生成 |

## 6. 使用建议

- 第一次试用先用较粗的容量步长，避免生成过多方案；
- 方案数很大时，逐小时详表 ZIP 会很大，导出时间也会变长；
- 对外沟通时应说明：方案概览是技术遍历结果，不是最终推荐结论；
- 若需要经济性排序、推荐方案或图表分析，应使用完整 Streamlit 主程序。
