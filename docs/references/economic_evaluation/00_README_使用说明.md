# 经济性评价 V1 资料包说明

本目录用于约束绿电直连 / 风光储项目经济性评价 V1 的简化计算口径。

当前目录已精简为三类文件：

- `00_README_使用说明.md`：本说明。
- `经济性评价V1计算口径_合并版.md`：唯一权威计算口径，开发前优先阅读。
- `99_官方来源清单.md`：法规和政策来源索引，仅作口径依据，不替代专业税务意见。

此前的分章节草稿已合并进 `经济性评价V1计算口径_合并版.md`，后续不要再新增平行版本。若经济性口径发生变化，优先更新合并版和 `notes/PRODUCT_POLISH_LOG.md`。

如果第一次接触经济性和推荐模块，建议先读 `docs/ECONOMY_RECOMMENDATION_V1_MAP.md`。该文档不是新口径，而是把电源侧、同一主体、负荷侧和推荐席位的代码入口、参数和输出串联成导览图。

## V1 定位

V1 是不考虑贷款的项目投资现金流评价模型，回答：

```text
给定风电、光伏、储能规模和年度技术结果后，
项目每年的收入、成本、税费、净现金流如何，
FNPV、FIRR、静态回收期、动态回收期如何。
```

V1 不改变技术调度结果，只读取技术 `summary` / `hourly_detail` 汇总字段。

## 必读规则

开发经济性模块前读取：

```text
docs/references/economic_evaluation/经济性评价V1计算口径_合并版.md
docs/references/economic_evaluation/99_官方来源清单.md
```

并遵守：

- 年度明细表是主输出，FNPV/FIRR/回收期必须能追溯到年度现金流。
- 用户输入的投资、电价、收入和成本默认是含税金额。
- 利润表使用不含税口径；现金流表使用实际含税现金收付。
- FIRR 不使用折现率；折现率只用于 FNPV、折现现金流和动态回收期。
- Year 0 为建设期，运营期默认 25 年，各年现金流默认年末发生。
- 运行成本 V1 不考虑进项税；建设投资和储能更换外购设备材料考虑进项税。
- 不实现贷款、流动资金、残值回收、无形资产摊销、即征即退、留抵退税、复杂融资和其他税种。
