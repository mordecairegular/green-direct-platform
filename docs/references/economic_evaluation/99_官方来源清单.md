# 99 官方来源清单

本资料包采用“简化计算口径”。以下来源用于帮助开发者理解基本法律和财税依据，但软件 V1 不追求完整税务申报。

## 1. 增值税

### 《中华人民共和国增值税法》

来源：国家税务总局税收政策法规库  
链接：https://fgk.chinatax.gov.cn/zcfgk/c100009/c5237365/content.html

与 V1 相关的基本原则：

- 增值税为价外税；
- 销项税额按销售额和税率计算；
- 进项税额可依法从销项税额中抵扣；
- 销售额不包括按一般计税方法计算的销项税额；
- 进项大于销项的部分可按规定结转或处理。V1 仅做留抵结转，不做留抵退税。

## 2. 企业所得税

### 《中华人民共和国企业所得税法》

来源：国家税务总局广东省税务局法规库  
链接：https://guangdong.chinatax.gov.cn/gdsw/zjfg/2018-03/17/content_5962c3b3c2664253ab801c00a9af7e1f.shtml

与 V1 相关的基本原则：

- 企业所得税基本税率为 25%；
- 应纳税所得额以收入总额减除不征税收入、免税收入、各项扣除以及允许弥补的以前年度亏损后的余额确定。

### 《中华人民共和国企业所得税法实施条例》

来源：国家税务总局税收政策法规库  
链接：https://fgk.chinatax.gov.cn/zcfgk/c100010/c5194417/content.html

与 V1 相关的基本原则：

- 固定资产按照直线法计算的折旧准予扣除；
- 企业可根据固定资产性质和使用情况合理确定预计净残值；
- V1 为简化项目经济性评价，统一按残值 0 处理。

## 3. 城建税

### 《中华人民共和国城市维护建设税法》

来源：全国人大法律法规数据库  
链接：https://wb.flk.npc.gov.cn/flfg/WORD/bd74e8aa2b054eae9d3af21a6f147300.docx

与 V1 相关的基本原则：

- 城建税以纳税人依法实际缴纳的增值税、消费税税额为计税依据；
- 税率为：市区 7%，县城、镇 5%，其他地区 1%；
- V1 不考虑消费税，因此简化为以实际缴纳增值税为基础。

## 4. 教育费附加

### 《征收教育费附加的暂行规定》

来源：国家行政法规库  
链接：https://xzfg.moj.gov.cn/front/law/detail?LawID=102

与 V1 相关的基本原则：

- 教育费附加以实际缴纳的增值税、营业税、消费税为计征依据；
- 教育费附加率为 3%；
- V1 不考虑营业税和消费税，因此简化为实际缴纳增值税 × 3%。

## 5. 地方教育附加

### 《财政部关于统一地方教育附加政策有关问题的通知》

来源：国家税务总局税收政策法规库  
链接：https://fgk.chinatax.gov.cn/zcfgk/c102416/c5194201/content.html

与 V1 相关的基本原则：

- 地方教育附加征收标准统一为实际缴纳增值税、营业税、消费税税额的 2%；
- V1 不考虑营业税和消费税，因此简化为实际缴纳增值税 × 2%。

## 6. 西部大开发企业所得税优惠

### 《财政部 税务总局 国家发展改革委关于延续西部大开发企业所得税政策的公告》

来源：国家税务总局上海市税务局法规库  
链接：https://shanghai.chinatax.gov.cn/zcfw/zcfgk/qysds/202005/t453507.html

与 V1 相关的基本原则：

- 2021 年 1 月 1 日至 2030 年 12 月 31 日，对设在西部地区的鼓励类产业企业减按 15% 税率征收企业所得税；
- 软件 V1 不自动判断是否符合优惠条件，只允许用户选择 15% 或自定义税率。

## 7. 使用提醒

本来源清单仅用于支持软件 V1 的简化财务评价口径，不构成税务申报建议。实际项目申报、纳税、审计、融资测算时，应以最新法律法规、地方政策、税务机关口径及专业机构意见为准。
