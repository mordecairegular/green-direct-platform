# 经济性评价 V1 计算口径

状态：2026-05-21 已确认，可作为代码实现依据。

## 1. 模块目标

经济性评价 V1 面向并网型绿电直连 / 风光储项目。它不是完整会计核算或税务申报模型，而是一个年度项目投资现金流模型。

V1 必须输出年度明细表，并从年度明细表汇总：

- 年度净现金流；
- 累计净现金流；
- 折现净现金流；
- 累计折现净现金流；
- 财务净现值 FNPV；
- 财务内部收益率 FIRR；
- 静态投资回收期；
- 动态投资回收期。

所有核心指标必须能追溯到年度明细，不允许只输出汇总指标。

## 2. 时间口径

V1 固定采用：

```text
Year 0：建设期，发生初始建设投资现金流出，不折现。
Year 1...N：运营期，默认 N = 25。
```

运营期收入、成本、税费和储能更换默认在每年年末发生。

折现系数：

```text
discount_factor_t = 1 / (1 + discount_rate) ** t
```

折现率只用于 FNPV、折现净现金流和动态投资回收期。FIRR 由项目净现金流序列反推，不使用用户输入的折现率。

## 3. 技术结果输入

经济性模块不重新计算调度，不改变 SOC、上网、下网、弃电、储能充放电。它只读取技术测算结果。

第一版使用 `summary` 字段：

| 字段 | 用途 |
|---|---|
| `scenario_id` | 经济结果和技术结果关联主键 |
| `wind_capacity` | 风电投资、风电运维、折旧 |
| `pv_capacity` | 光伏投资、光伏运维、折旧 |
| `bess_power` | 储能运维 |
| `bess_energy` | 初始储能投资、储能更换投资 |
| `grid_export_energy` | 上网电费收入 |
| `self_use_energy` | 自发自用电费收入 |
| `annual_equivalent_cycles` / `replacement_year` | 推导储能更换年份 |

当前项目容量单位为万千瓦，电量单位为万千瓦时，经济输出建议统一为万元。由于“万”与“元”换算刚好抵消：

```text
投资（万元） = 容量（万kW 或 万kWh） * 单价（元/kW 或 元/kWh）
收入（万元） = 电量（万kWh） * 电价（元/kWh）
```

| 投资 | 储能单位造价 | 900 | 元/kWh，含税 | 乘储能电量 |

| 投资税率 | 建设投资进项税率 | 10% | % | 可改 |

光伏单位造价提示语：

```text
光伏单位造价需与光伏标幺曲线的容量基准一致。
若光伏曲线按直流侧容量归一化，请输入直流侧单位造价；
若按交流侧并网容量归一化，请输入交流侧单位造价。
```

## 5. 营业收入

V1 只使用以下收入名称：

```text
营业收入 = 上网电费收入 + 自发自用电费收入 + 其他经营收入
```

公式：

```text
含税上网电费收入 = grid_export_energy * grid_export_price_with_vat
含税自发自用电费收入 = self_use_energy * self_use_price_with_vat
含税营业收入 = 含税上网电费收入 + 含税自发自用电费收入 + 含税其他经营收入
```

禁止使用以下名称：

```text
节省购电成本
替代购电收益
内部绿电结算收益
内部结算收入
绿电溢价收益
等价收益
```

其他经营收入支持多项。每项建议包含：

```text
name
amount_with_vat_wan_yuan_per_year
vat_rate
active_rule: every_year / first_20_years / first_25_years / specific_years
specific_years: [年序号...]
```

其他经营收入可以为负值。负值默认不产生销项税，也不产生进项税，只作为经营性收入抵减或额外经营性支出进入现金流。

## 6. 年运行成本

V1 年运行成本简化为：

```text
年运行成本 = 风电运维费 + 光伏运维费 + 储能运维费 + 其他运行成本
```

默认口径：

```text
风电运维费（万元） = wind_capacity * 50
光伏运维费（万元） = pv_capacity * 25
储能运维费（万元） = bess_power * 18
```

V1 运行成本视为公司内部运行维护，不考虑进项税。因此：

```text
不含税年运行成本 = 含税年运行成本
运行成本进项税额 = 0
```

储能电池更换支出单独列示，不并入年运行成本。

## 7. 建设投资与折旧

初始建设投资含税金额：

```text
风电投资含税 = wind_capacity * wind_capex_unit_with_vat
光伏投资含税 = pv_capacity * pv_capex_unit_with_vat
初始储能投资含税 = bess_energy * bess_capex_unit_with_vat
其他固定资产投资含税 = 用户输入
建设投资现金流出 = 上述投资含税合计
```

建设投资可抵扣进项税：

```text
建设投资不含税金额 = 建设投资现金流出 / (1 + 建设投资进项税率)
建设投资进项税额 = 建设投资现金流出 - 建设投资不含税金额
```

Year 0 通常无销项税，建设投资进项税形成期末留抵，进入运营期抵扣。

折旧：

```text
风电、光伏、初始储能、其他固定资产：20 年，残值 0，直线法。
运营第 1 年至第 20 年计提折旧。
运营第 21 年及以后初始资产折旧为 0。
```

如果投资项可抵扣进项税，折旧基础为不含税金额；如果投资项不可抵扣，折旧基础为含税金额。V1 默认初始投资可抵扣。

折旧不是现金流出，但影响利润总额和企业所得税。

## 8. 增值税

V1 只实现一般计税的简化模型：

```text
可用抵扣额 = 当年进项税额 + 期初留抵税额
实际缴纳增值税 = max(当年销项税额 - 可用抵扣额, 0)
期末留抵税额 = max(可用抵扣额 - 当年销项税额, 0)
```

销项税来自：

```text
上网电费收入
自发自用电费收入
正值其他经营收入
```

进项税来自：

```text
Year 0 建设投资可抵扣进项税
储能更换可抵扣进项税
```

运行成本进项税 V1 取 0。

进项税不直接作为现金流入，只通过减少实际缴纳增值税或形成留抵体现。

## 9. 附加税费

V1 中附加税费只以实际缴纳增值税为计税基础，不考虑消费税。

```text
城建税 = 实际缴纳增值税 * 城建税税率
教育费附加 = 实际缴纳增值税 * 3%
地方教育附加 = 实际缴纳增值税 * 2%
附加税费合计 = 城建税 + 教育费附加 + 地方教育附加
```

城建税税率：

```text
市区：7%
县城、镇：5%，默认
其他地区：1%
```

不要把政府性基金及附加放入本模块。

## 10. 企业所得税

默认企业所得税税率为 25%，允许用户选择 15% 或自定义税率。软件不自动判断优惠资格。

简化公式：

```text
利润总额 = 不含税营业收入 - 不含税年运行成本 - 折旧 - 附加税费
应纳税所得额 = max(利润总额 - 可弥补亏损, 0)
企业所得税 = 应纳税所得额 * 企业所得税税率
净利润 = 利润总额 - 企业所得税
```

V1 可实现简化亏损弥补；如果暂不实现，必须在结果说明中标注“未考虑亏损弥补”。

## 11. 储能电池更换

储能电池更换采用 V1 简化口径：

- 只作为当年现金流出；
- 考虑进项税抵扣或留抵；
- 不追加折旧；
- 不计算残值；
- 不计算旧电池处置。

更换金额：

```text
储能更换现金流出 = 初始储能投资含税 * 储能更换投资比例
```

更换进项税：

```text
储能更换不含税金额 = 储能更换现金流出 / (1 + 更换进项税率)
储能更换进项税额 = 储能更换现金流出 - 储能更换不含税金额
```

更换触发：

```text
replacement_operation_year = ceil(replacement_year)
```

如果 `replacement_operation_year` 小于运营期最后一年，则在该运营年年末发生更换。若到第 25 年才触发更换，默认不再更换。更一般地，若触发年份大于等于运营期最后一年，默认不进行更换。

## 12. 项目净现金流

V1 项目净现金流采用直接现金收付法：

```text
项目净现金流 =
  含税营业收入
- 含税年运行成本
- 建设投资现金流出
- 储能更换现金流出
- 实际缴纳增值税
- 附加税费
- 企业所得税
```

说明：

- 利润表用不含税口径；
- 现金流表用实际含税现金收付；
- 折旧不作为现金流出；
- 不考虑贷款、还本付息和融资利息；
- 不考虑流动资金投入与回收；
- 不考虑期末残值回收。

## 14. 指标计算

累计净现金流：

```text
cumulative_net_cash_flow_t =
  cumulative_net_cash_flow_(t-1) + net_cash_flow_t
```

FNPV：

```text
FNPV = sum(discounted_net_cash_flow)
```

FIRR：

```text
sum(net_cash_flow_t / (1 + FIRR) ** t) = 0
```

如果现金流没有有效变号、存在多次变号导致无法可靠求解，或算法异常，应返回明确状态和提示，例如：

```text
firr = None
firr_status = "IRR 无法可靠计算"
```

不要返回误导性数值。

静态投资回收期以累计净现金流由负转正为准，可插值：

```text
payback = 转正前一年份 + abs(转正前累计净现金流) / 转正当年净现金流
```

动态投资回收期以累计折现净现金流由负转正为准，同样可插值。

## 15. V1 禁止引入内容

不要实现：

- 贷款、还本付息、资本金 IRR、复杂融资模型；
- 流动资金；
- 无形资产摊销；
- 即征即退；
- 留抵退税；
- 消费税；
- 政府性基金及附加；
- 输配电费；
- 系统运行费；
- 政策性交叉补贴；
- 印花税、房产税、城镇土地使用税、土地增值税等其他税种；
- 递延所得税；
- 绿证收益、碳收益、辅助服务收益；
- 复杂电力市场结算费用。

如确有其他收入或成本，V1 统一通过“其他经营收入”表达；负值按收入抵减或经营性支出处理。

## 16. 最小测试要求

实现代码时至少覆盖：

1. 无建设投资进项税时，正常缴纳增值税；
2. Year 0 建设投资进项税形成留抵，运营期逐年抵扣；
3. 储能更换当年产生大额进项税，导致当年增值税减少或形成留抵；
4. 风电、光伏、初始储能按 20 年、残值 0、直线折旧；
5. 运营期超过 20 年时，第 21 年后初始资产折旧为 0；
6. 实际缴纳增值税为 0 时，附加税费为 0；
7. 企业所得税税率 25% 和 15% 两种情形；
8. FIRR 无法计算时返回明确提示而不是错误数值；
9. 不考虑流动资金和残值回收时，现金流表不出现相关字段；
10. 运行成本进项税为 0；
11. 其他经营收入为负值时不产生进项税；
12. 储能更换若触发在运营期最后一年或之后，默认不更换；
13. 经济性评价不修改技术 `summary` 和 `hourly_detail`。
